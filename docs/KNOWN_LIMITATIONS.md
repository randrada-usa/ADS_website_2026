# Known Limitations

These items are unfinished or need final project decisions.

## Content

- Final text, member details, activities, dates, FAQs, and links are still being added.
- Demo text and temporary images can appear when Sanity is not connected.
- A content-editing guide will be written after the content workflow is final.

## Partner logos

- PNG logos have not been converted to WebP yet. Wait until the final logos are approved.
- Logos use the same frame size, but some may still need visual size adjustments.
- `assets/Partners/` is local and ignored by Git. The website uses `public/assets/partners/`.

## Sanity

- Real account permissions, publishing, preview access, and recovery still need final testing.
- Only approved public information should be uploaded to Sanity.
- Published changes may need a refresh after the cache updates.

## Deployment

- Hosting, domain, analytics, monitoring, and account ownership are not final.
- The deployment guide will be written after these decisions are made.

## Final testing

- Real iPhone, Android, Safari, keyboard, zoom, reduced-motion, and screen-reader checks are still required.
- Animation performance should be tested in a production build on a normal mobile device.

The website is not ready for final sign-off until the QA checklist is complete.
